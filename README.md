# junior-nisa

2027年開始の0〜17歳向けNISA制度を、一次情報ベースで解説する教育サイトです。

## 方針
- 金融庁・財務省・国税庁の一次資料を優先
- 確定事項と未確定の金融機関実務を分離
- 投資推奨や個別税務助言は行わない
- Mobile First / Astro / static-first / minimal JavaScript
- シミュレーターは参考試算であり、将来の運用成果を保証しない

## 開発
```bash
npm install
npm run dev
npm run build
```
